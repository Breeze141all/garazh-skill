# cartoon-reel

Из идеи в одну строку получается готовый mp4. `${CLAUDE_SKILL_DIR}` — каталог этого скилла (Claude Code подставляет его сам). Движок — студия `$STUDIO`: `$CARTOON_STUDIO`, иначе `~/Documents/cartoon-studio.nosync` (если есть), иначе `~/cartoon-studio` — ровно так её ищут скрипты (`scripts/studio-path.sh`). Каждый эпизод — это данные (`episodes/<ep>/timeline.js` + `sfx.mjs`) поверх общего движка `src/`.

## Перед стартом
0. Не клади студию в синхронизируемую облаком папку (на macOS — «Документы» с iCloud) без суффикса `.nosync`: на заполненном диске macOS выгружает исходники в облако (файлы становятся `dataless`, рендер падает со странными ошибками). Промежуточные кадры `.frames` после финального рендера удаляй — это гигабайты (80 с ролика ≈ 10 ГБ PNG).
1. Если студии нет, разверни её: `bash ${CLAUDE_SKILL_DIR}/scripts/bootstrap.sh [dir]`. Нужны node ≥18, ffmpeg и Google Chrome (или `CHROME_PATH=/путь/к/chromium`). Ключ нужен только для озвучки: `OPENROUTER_API_KEY` **или** `FISH_AUDIO_API_KEY` в `$STUDIO/.env` (шаблон — `.env.example`); без ключа всё остальное работает, а готовые реплики берутся из кэша.
2. Прочитай `references/style-guide.md`. Это закон по визуалу и ритму.
3. Посмотри эталоны (Read): `references/images/ours_v2_sheet.jpg` — эпизод `tolyan`, `references/images/garazh_sheet.jpg` — эпизод `garazh` (кадр в секунду). Если есть `references/images/private/ref_*.jpg` — это локальные кадры исходного рилса-вдохновения (в публичный репозиторий не входят), сверяйся с ними.
4. API и команды лежат в `references/pipeline.md`. Сначала §1 «Пресеты» — это основной API; сырые координаты — аварийный выход.
   - раскладки `stage: { preset }`: `garage3` (Толян · Палыч · Санёк), `garage1` (один за столом), `blank`;
   - камеры `cam`: `'wide'`, `'two:a+b'`, `'cu:who'`, `'cu+:who'`, `'mid:who'`, `'screen'`, `'screen+'` (+ `{ preset, dx, dy, s, push }`);
   - позы `{ t, pose }`: `rest typing fingerUp spread point(at) reach(at) kiss thumbsUp hold(prop) sip phoneWaist phoneUp phoneChin phoneDown down`; голова `nod shake left right level`;
   - стартеры `node new-episode.mjs <ep> --preset garage3|garage1|blank` — рабочий эпизод, без ключа TTS (субтитры по оценке).

## Свой мультик по своему сюжету (главный сценарий использования)
Пользователь говорит «сделай мультик/рилс про …». Не переиспользуй готовые эпизоды — делай новый, в том же стиле:
1. **Сценарий.** Сначала уточни в одном сообщении (или выбери сам, если просили «на твой вкус»): тема, длина (8–90 с), мат да/нет, мораль/панч. Напиши `episodes/<ep>/script.md` по образцу `episodes/garazh/script.md`: логлайн, каст (внешность, проп-якорь, бейдж «ИМЯ / шуточные РОЛИ», тип голоса), акты, бит-шит таблицей (t, шот, кто в кадре, действие, реплика с тегами `[устало]`, субтитры, звук), список новых ассетов. Правила смешного — в style-guide §6–8: ≈1 бит/с, немая пауза перед реакцией, панч одним словом, мораль через поворот, не лекцией. Покажи пользователю логлайн + каст + финал до производства.
2. **Голоса** (если нужна озвучка). Каталог Fish без ключа: `curl -s "https://api.fish.audio/model?page_size=40&language=ru&sort_by=task_count"` → поле `_id` = ID голоса. Подбирай по тегам (male/old/young/calm…). Голоса-двойники реальных людей не бери. Свой голос пользователя — его ID с fish.audio. Сгенерируй реплики заранее (`voice/build.mjs --check`) и раскладывай шоты под реальные длительности, а не под оценку в сценарии (образец — `episodes/garazh/shots.md`).
3. **Персонажи.** Толян, Палыч и Санёк уже в `src/characters/` — бери их. Новый герой = файл `episodes/<ep>/art/<who>.js`, регистрирующий `CHARS.<who> = { rig, anchors, body(st,P), head(st,P) }` в системе координат 720×1280 (голова ≈360,590, плечи y≈800). Образцы: `src/characters/palych.js` (широкий, шапка, очки-проп), `sanek.js` (узкий, капюшон, телефон). Силуэты героев должны контрастировать (масса, головной убор, проп). Сначала проверь героя на отдельном кадре, потом ставь в сцену.
4. **Декорация и пропы.** Гараж (`src/sets/garazh.js`), чайник/кружка/телефон (`src/props/`) уже есть — раскладки `garage3`/`garage1`. Новая локация: `episodes/<ep>/art/set.js` (задник `…Back(t, env)` и передний план `…Front(t, env)`, мир шире кадра для двушек) + свои `PROPS` — тот же контракт, подключаются через `scripts` и `stage`.
5. **Таймлайн** (`episodes/<ep>/timeline.js`): `stage: { preset }` → `shots` (set `stage`/`chat`, `cam` строкой: `wide`, `two:a+b`, `cu:who`, `screen`, `mode:'blackout'`) → `voice` → `badges` → `env` (состояние сцены) → `chat` (если есть экран Claude) → `cast` (позы `{ t, pose }`, треки, события на каждого). API — `references/pipeline.md` §1 (пресеты) и §4.
6. Дальше общий процесс ниже: стиллы → контакт-лист → правки → финал с `--voice --sfx` → звук эпизода в `episodes/<ep>/sfx.mjs` (времена только из TIMELINE).

## Процесс
1. **Бит-шит** (сначала в чат, до кода). Примерно 1 бит в секунду. Структура: подводка → вставка экрана или действие → крупный план реакции. Немой шок 0.5–0.8 с, потом пауза, потом панчлайн одним словом. Финальный кадр держать ≥0.6 с.
2. **Эпизод:** `cd $STUDIO && node new-episode.mjs <ep> --preset garage3` — рабочий стартер на пресетах, сразу рендерится. Примеры: `episodes/tolyan/` (8 с, один персонаж, сырые координаты), `episodes/garazh/` (80 с, трое, чат, блэкауты, озвучка — сценарий `script.md`, раскладка `shots.md`).
3. **TIMELINE**: в нём только литералы. Все тайминги живут тут; сеты и звук берут их из таймлайна.
4. **Новые персонажи и сеты** кладутся в `episodes/<ep>/` и подключаются через `TIMELINE.scripts`. В `src/` переносить, только когда нужно ≥2 эпизодам. Правки `src/` должны быть обратно-совместимы: стиллы `tolyan` и `garazh` до и после правки сравнивать через `cmp`.
5. **Стиллы** (около 1 с): `FRAMES_DIR=/tmp/rv node render.mjs --ep <ep> --stills 0.5,2.1,…`. Смотри PNG сам, не рендери целиком вслепую.
6. **Превью и контакт-лист:** `node render.mjs --ep <ep> /tmp/p.mp4 --preview`, затем `ffmpeg -v error -i /tmp/p.mp4 -vf "select=not(mod(n\,10)),scale=180:-1,tile=6x4" -frames:v 1 -y /tmp/c.png`. Положи рядом с эталонными листами и сравни.
7. **Озвучка (если эпизод говорит):** реплики — в `TIMELINE.voice` (cast + lines с тегами `[устало]`), субтитры и рот из них выводятся сами (без ключа — по оценке длительности, стиллы работают). `node --env-file=.env voice/build.mjs --ep <ep> --check` — TTS только новых реплик (кэш), STT-проверка слов (`--check` — только с OpenRouter). Голоса — ID моделей fish.audio в `voice.cast`; ищи по каталогу, избегай голосов-двойников реальных людей. Раздел «Озвучка» в `references/pipeline.md`. Ключ в `.env`, в чат/шаблон не копировать.
8. **Финал:** `node render.mjs --ep <ep> out/<ep>_vN.mp4 --final --sfx` (с озвучкой — `node --env-file=.env render.mjs … --voice --sfx`; кадры `.frames` удаляются сами, `--keep-frames` — оставить). Это около 20 с на 8 с ролика. Проверь ffprobe: 720×1280, 30/1, длительность = `TIMELINE.duration`, есть aac-дорожка. Старые версии не перезаписывать.
9. **Сдача:** отправь mp4 пользователю (SendUserFile) с бит-шитом. Если улучшал общий движок, синхронизируй шаблон скилла: `bash ${CLAUDE_SKILL_DIR}/scripts/sync-template.sh`.

## Разделение ролей (если подключаешь сабагентов)
- Визуальные решения принимает основная сессия: форма, цвет, кадр, позы. Критику визуала от сабагентов считать мнением.
- Сабагентам с самой сильной моделью рассуждений (если есть выбор модели) отдавать «думающее»: архитектуру (риг, новые системы), логику и тайминг шутки, ревью кода и детерминизма.
- Параллельные агенты работают в разных файлах. Владение файлами прописывать в брифе явно.

## Частые ошибки
- Обведённые кирпичи, чёрный контур, глаза-блюдца, плавающие позы, наклонённая плашка субтитров. Всё это ломает стиль.
- Радужный или цветной свет на весь кадр. Цветной свет кладётся маской только на кожу.
- Литералы времени в `src/` или `sfx.mjs` вместо таймлайна: тайминги разъедутся.
- `Math.random` или `Date` в сцене. Только `rng(seed)` и `t`.
- Несколько персонажей в кадре — только через сет `stage` и реестр `CHARS` (pipeline.md §4.7): движок сам префиксует SVG-id и рисует руки/наклон головы; `CHARS.<who>.head` — без наклона, `body` — без рук.
- Свой сет с персонажем обязан вызвать `${tolyan(st)}`, а после предметов переднего плана `${armsSvg(st.arms,'front')}`.
- Субтитр длиннее ~24 символов не влезет в строку.
